# ManagerWall

Educational password manager written in C#/.NET.

## Current features

- Master password
- AES-256 encryption
- Encrypted local storage
- JSON serialization
- Add accounts
- View accounts
- Delete vault

## Status

🚧 Work in progress.

This project is primarily educational and should not be used
to store real sensitive passwords yet.
